# 📚 Exam Dashboard

A modern, responsive Exam Dashboard web application built using **React JS** and **Tailwind CSS**. This dashboard helps students and administrators manage exams, view performance, and organize learning material in a streamlined and intuitive UI.

---

## 🚀 Features

- 🔐 **User Authentication** – Secure login and registration system (JWT/Session-based)
- 📝 **Create and Manage Exams** – Add, edit, and schedule exams for different classes or subjects
- 📊 **Student Performance Tracking** – Real-time performance reports and analytics
- 📅 **Exam Schedule View** – Clean and simple interface to track upcoming and completed exams
- 🌐 **Fully Responsive UI** – Optimized for mobile, tablet, and desktop
- 🎨 **Modern UI with Tailwind CSS** – Beautiful, minimal design with custom styling
- 🔄 **Dynamic Routing** – Powered by React Router for seamless navigation

---

## 🧱 Tech Stack

- **Frontend:** React JS, Tailwind CSS
- **Routing:** React Router
- **State Management:** React Context API / Redux (if used)
- **API Integration:** Axios / Fetch API
- **Icons:** Heroicons / React Icons

```bash

# Navigate into the project directory
